    What is actually collected

    What we receive

    • How many repairs were recorded, and how many were fixed
    • How many sessions were held, and how many volunteers helped
    • The kinds of thing repaired, from a shared list of item types
    • Which version of the software is running

    What we never receive

    • Names of people, volunteers or visitors
    • Anything a visitor told a cafe, or any contact details
    • Item descriptions, fault notes, or any other typed text
    • Photographs, and no address is ever stored

    There is no free-text field anywhere in the message, so nothing personal can travel with it even by accident. A café's name and location only appear above if it explicitly asked to be on the map, and the pin comes from its own public listing on repaircafe.org rather than from anything we were told.

    Running a hub?

    Sharing is off until somebody turns it on. To change it, go to Settings, then Sharing our numbers, where you can also see the exact message your hub would send and ask us to delete everything we hold about you. To rule it out before the software first starts, set TELEMETRY_DISABLED=true.
